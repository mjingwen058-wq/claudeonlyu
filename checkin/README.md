# VINCI 2026 观众签到 · 交互原型

「无界未来 FUTURES UNBOUND」展览（2026.11.1–11.15，杭州）的扫码签到原型，视觉照 KV 做：白底、点线参考线、ASCII 主视觉、四色小方块。

- `index.html`：观众端和后台在同一个页面里，顶部黑条切换
- `assets/`：从 KV 裁出来的标题字、VINCI 标志、ASCII 主视觉、底部条纹

## 怎么打开

```bash
cd checkin
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。后台演示密码 `vinci2026`。

## 原型里是怎么演示的

- 演示时间从 11 月 3 日 15:30 开始走，后台预置了 11/1–11/3 的模拟签到
- 观众端提交的签到存在当前浏览器里，切到后台马上能看到
- 「下次提交模拟网络失败」可以看提交失败时的样子
- 「换一位观众重新签到」会清掉本机的签到状态
